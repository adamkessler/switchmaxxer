# Agent Guidance

Coding agents working in this repository should use best practices whenever possible.

Prefer the project’s existing patterns, APIs, and style before introducing new abstractions. Keep changes scoped to the user’s request, preserve security-sensitive defaults, update tests and documentation when behavior changes, and avoid reverting user or agent work that is unrelated to the current task.

Use spaces for indentation, matching the surrounding file style. TypeScript, JSON, and project docs generally use two-space indentation.
